# Risiti Loop

Hackathon prototype that rewards customers for verifying simulated ZRA Smart Invoice receipts.

- [`contract/api-contract.md`](contract/api-contract.md) — single source of truth for the API.
- [`backend/README.md`](backend/README.md) — backend setup, run instructions and curl examples.

The frontend lives in `frontend/` and is maintained separately. All ZRA and Zamtel integrations
are simulated.
